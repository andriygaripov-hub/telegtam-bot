# Telegram Bot - Виробничі оповіщення

Автоматичні оповіщення в телеграм каналі для виробничих операцій.

## Налаштування

### 1. Створіть телеграм бота
- Напишіть [@BotFather](https://t.me/botfather) в Telegram
- Отримайте `TELEGRAM_BOT_TOKEN`

### 2. Отримайте ID каналу
- Додайте бота до вашого приватного каналу
- Отримайте `TELEGRAM_CHANNEL_ID` (формат: `-100...` для групи/каналу)

### 3. Встановіть секрети в GitHub
Перейдіть до **Settings → Secrets and variables → Actions** і додайте:

| Секрет | Значення |
|--------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен від BotFather |
| `TELEGRAM_CHANNEL_ID` | ID вашого каналу |

## Тестування

Натисніть кнопку **"Run workflow"** в GitHub Actions для негайного тесту оповіщення.

## Часові зони

Розклади встановлені для **UTC**. Якщо потрібна інша часова зона, адаптуйте cron вирази.
